# FlipTrack Pro - Chrome Extension

## Quick Start

### Installation

1. Extract this zip file
2. Open Chrome
3. Go to `chrome://extensions/`
4. Enable "Developer mode" (top-right)
5. Click "Load unpacked"
6. Select this folder
7. Done! Extension appears in toolbar

### Testing

1. Go to flipkart.com
2. Click on any product page
3. You'll see "📌 Track Price" button
4. Click to add to tracking
5. Click extension icon to see tracked products

### Files Included

- `manifest.json` - Extension configuration
- `background.js` - Service worker
- `popup.html/js` - Popup UI
- `content.js` - Flipkart page injection
- `options.html` - Settings page
- `styles.css` - Material Design 3 styles
- `icons/` - Place your icons here (16x16, 48x48, 128x128 PNG)
