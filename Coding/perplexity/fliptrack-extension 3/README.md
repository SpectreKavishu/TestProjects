# FlipTrack Pro - Chrome Extension

## 🚀 QUICK START (2 Minutes)

### Step 1: Load in Chrome
1. Open Chrome
2. Go to `chrome://extensions/`
3. Toggle "Developer mode" ON (top-right)
4. Click "Load unpacked"
5. Select this folder
6. ✅ Extension loaded!

### Step 2: TEST IT
1. Click extension icon in toolbar
2. Go to flipkart.com
3. Click any product
4. Wait 1-2 seconds...
5. You'll see "📌 Track Price with FlipTrack" button
6. Click it
7. See "✅ Added to FlipTrack!" message
8. Click extension icon - product appears!

## TROUBLESHOOTING

**Button not appearing?**
1. Make sure you're on flipkart.com
2. Hard refresh the page (Ctrl+Shift+R)
3. Check console for errors (F12)

**Message not showing?**
1. Wait 1-2 seconds for page to load
2. Check DevTools console
3. Make sure extension is loaded

**Want to debug?**
1. Press F12 on Flipkart page
2. Go to Console tab
3. Look for [FlipTrack] messages
4. Check for any errors
